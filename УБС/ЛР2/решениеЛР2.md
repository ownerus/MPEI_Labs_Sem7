# УБС. Лабораторная работа № 2

**Тема:** Синтез структуры больших систем управления. Распределение задач по узлам управления.

**Группа 3, бригада 3.** Грудинин Е. К., Турханов А. К.

**Цель:** применить метод ветвей и границ к распределению задач по узлам управления при ограничении на суммарное время.

Источник: [«Лабораторные работы УБС»](../Лабораторные%20работы%20УБС.docx), §§ 2.2–2.6.

## 1. Исходные данные и постановка задачи

Есть пять задач и четыре узла. Строка `i` соответствует задаче, столбец `j` — узлу. По § 2.4 заменяем первый столбец обеих матриц; остальные столбцы берём из примера методички. Для пересчёта задан лимит `Tз = 30`.

```text
C[i,1] = T[i,1] = (3 + 3 + i) / 2,  i = 1,…,5.

       узел:  1    2    3    4           узел:  1    2    3    4
          ┌                    ┐            ┌                    ┐
          │  3,5   7    2    2 │            │  3,5   3    2    9 │
          │  4     8    1    3 │            │  4     6    5   10 │
      C = │  4,5   9    6    2 │        T = │  4,5   7    6   11 │
          │  5    10    7    1 │            │  5     8    7   12 │
          │  5,5   5    3    1 │            │  5,5   9    8    5 │
          └                    ┘            └                    ┘
```

`x[i,j] = 1`, если задачу `i` назначили узлу `j`, иначе `x[i,j] = 0`. Каждую задачу назначаем ровно одному узлу. Один узел может выполнять несколько задач; лимит наложен на сумму времён всех задач, а не на загрузку отдельных узлов.

```text
Минимизировать F(x) = Σ(i=1…5) Σ(j=1…4) C[i,j] · x[i,j]
при условии    t(x) = Σ(i=1…5) Σ(j=1…4) T[i,j] · x[i,j] ≤ 30;
                      Σ(j=1…4) x[i,j] = 1,  i = 1,…,5;
                      x[i,j] ∈ {0, 1}.
```

## 2. Преобразование матриц

**Исключение доминируемых назначений.** В одной строке узел `j` можно исключить, если другой узел `k` требует не больше затрат и времени, причём хотя бы по одному показателю он строго лучше. Замена `j` на `k` не ухудшает решение и не нарушает ограничения модели.

| Задача | Остаются узлы | Исключаются узлы (замена) |
|---:|:---|:---|
| 1 | 3 | 1, 2, 4 → 3 |
| 2 | 1, 3 | 2 → 1; 4 → 3 |
| 3 | 1, 4 | 2, 3 → 1 |
| 4 | 1, 4 | 2, 3 → 1 |
| 5 | 4 | 1, 2, 3 → 4 |

```text
          ┌                    ┐            ┌                    ┐
          │   —    —    2    — │            │   —    —    2    — │
          │   4    —    1    — │            │   4    —    5    — │
   C⁽⁰⁾ = │   4,5  —    —    2 │     T⁽⁰⁾ = │   4,5  —    —   11 │
          │   5    —    —    1 │            │   5    —    —   12 │
          │   —    —    —    1 │            │   —    —    —    5 │
          └                    ┘            └                    ┘
```

**Проверка по времени.** Для фиксированной пары «задача `r` — узел `j`» прибавляем к её времени минимальные времена остальных задач. Это нижняя оценка по формуле (2.9). Минимумы считаем по матрице `T⁽⁰⁾` до исключений на этом шаге.

```text
m[i] = min по оставшимся узлам k из T[i,k]
L[r,j] = T[r,j] + Σ(i ≠ r) m[i]

(m[1], m[2], m[3], m[4], m[5]) = (2; 4; 4,5; 5; 5)
Σ(i=1…5) m[i] = 20,5 ≤ 30.
```

| Задача | Нижняя оценка времени при фиксации каждого оставшегося узла |
|---:|:---|
| 1 | узел 3: 20,5 |
| 2 | узел 1: 20,5; узел 3: 21,5 |
| 3 | узел 1: 20,5; узел 4: 27 |
| 4 | узел 1: 20,5; узел 4: 27,5 |
| 5 | узел 4: 20,5 |

Ни одна оценка не превышает 30. На этом шаге дополнительных исключений нет: `C⁽¹⁾ = C⁽⁰⁾`, `T⁽¹⁾ = T⁽⁰⁾`. Совместный выбор нескольких медленных узлов всё ещё может нарушить лимит.

## 3. Оценки и дерево решения

В вершине `X` дерева зафиксированы узлы `j₁,…,jₗ` для первых `l` задач. Нижние оценки стоимости и времени по формулам (2.7)–(2.8):

```text
V_C(X) = Σ(i=1…l) C[i,jᵢ] + Σ(i=l+1…5) min по оставшимся узлам j из C[i,j]
V_T(X) = Σ(i=1…l) T[i,jᵢ] + Σ(i=l+1…5) min по оставшимся узлам j из T[i,j]
```

В корне ничего не зафиксировано. По `C⁽⁰⁾` получаем `V_C = 2 + 1 + 2 + 1 + 1 = 7`; по `T⁽⁰⁾` получаем `V_T = 20,5`. Это две независимые оценки: минимумы стоимости и времени не обязаны достигаться на одном распределении.

В дереве запись `(3; 3; 4)` означает, что первые три задачи назначены узлам 3, 3 и 4. В квадратных скобках указаны `[V_C; V_T]`. Из открытых вершин выбираем вершину с наименьшей оценкой стоимости.

```text
X₀ [7; 20,5]
└── (3) [7; 20,5]
    ├── (3; 1) [10; 20,5] — отсечение по стоимости
    └── (3; 3) [7; 21,5]
        ├── (3; 3; 4) [7; 28]
        │   ├── (3; 3; 4; 4) [7; 35] — отсечение по времени
        │   └── (3; 3; 4; 1) [11; 28] — отсечение по стоимости
        └── (3; 3; 1) [9,5; 21,5]
            ├── (3; 3; 1; 1) [13,5; 21,5] — отсечение по стоимости
            └── (3; 3; 1; 4) [9,5; 28,5]
                └── (3; 3; 1; 4; 4) [9,5; 28,5] — рекорд
```

Например, если задачи 3 и 4 назначить узлу 4, нижняя оценка времени на ветви `(3; 3; 4; 4)` составит `2 + 5 + 11 + 12 + 5 = 35 > 30`. После нахождения полного назначения с затратами 9,5 оставшиеся оценки стоимости 10, 11 и 13,5 выше рекорда. Ни одна из этих ветвей не может улучшить результат.

## 5. Блок-схема алгоритма

```text
Начало
  ↓
Ввести C, T и лимит Tз
  ↓
Исключить доминируемые пары в каждой строке
  ↓
Вычислить минимумы времени по строкам и оценки L[r,j]
  ↓
Исключить пары с L[r,j] > Tз
  ↓
Есть строка без допустимых узлов? ── да → Нет решения → Конец
  │ нет
  ↓
Корень в список открытых вершин; рекорд R = ∞
  ↓
Список пуст? ── да → Вывести назначение и R,
  │ нет              либо «нет решения», если R = ∞ → Конец
  ↓
Извлечь вершину X с наименьшей оценкой V_C
  ↓
V_T(X) > Tз или V_C(X) ≥ R? ── да → Отбросить X
  │ нет                                    │
  ↓                                        │
Все задачи назначены?                      │
  ├─ да  → Запомнить назначение; R = V_C(X) ┤
  └─ нет → Для следующей задачи создать    │
           по потомку на оставшийся узел,  │
           вычислить оценки и добавить     │
           потомков в список ──────────────┤
                                           ↓
                               Вернуться к «Список пуст?»
```

Для данных бригады поиск завершается с рекордом 9,5 после отсечения оставшихся ветвей.

## 6. Контрольные вопросы

1. **Что решает структурный синтез?** Выбирает состав элементов, связи и распределение функций так, чтобы система выполняла требования при заданных ресурсах.
2. **Как ставится задача?** Задают функции, возможные элементы и связи, ограничения и критерий. Например, распределяют вычислительные задачи по центрам, минимизируя затраты при лимите времени.
3. **Какие бывают критерии структурной оптимизации?** Минимум суммарных затрат при лимите времени, минимум суммарного времени при ограниченном бюджете или минимум максимальной загрузки узла.
4. **Как сравнить методы решения?** Полный перебор гарантирует точный ответ, но число вариантов быстро растёт. Метод ветвей и границ тоже даёт точный ответ при корректных оценках и отсекает целые подмножества, хотя в худшем случае приближается к перебору. Жадный метод быстрее, но без дополнительных свойств задачи не гарантирует оптимум.

**Вывод:** для группы 3 и бригады 3 при `Tз = 30` минимальные затраты равны 9,5, суммарное время — 28,5. Оптимальное назначение задач 1–5 по узлам: `(3; 3; 1; 4; 4)`. Программная часть не выполнялась.
