## SMath

На этом компьютере проверено приложение C:\Program Files (x86)\SMath Studio\Solver.exe, версия 1.5.0.9678. Откройте SMath_вариант_103.sm через Ctrl+O и дождитесь автоматического пересчёта. При открытии из папки сдачи лист пересчитался успешно. В нём 103 региона, 82 математических региона и 3 графика; точность вывода 10 знаков.

В разделе 3 показаны точная и четырёхчленная приближённая АФЧХ. В разделе 4 находятся Knyq, Khur, Kroot и корни при K=10. В разделе 5 функция Step формирует последовательность Y по разностному уравнению; yt(t) выбирает отсчёт. График строится непосредственно из этой последовательности. В разделе 6 приведены ошибки.

Контроль: Knyq=52.1204390184; Khur=52.1204390186; Kroot=52.1204389962; yt(0.1)=0.2314325309; yt(60)=0.999999971; est=0; ekin=0.05. Малые отличия последних знаков от Python связаны с численной арифметикой. Файл не требует внешних таблиц или Python для пересчёта.

## SimInTech

Извлеките весь комплект в одну папку, сохранив вложенную папку output. Откройте SimInTech_модель_вариант_103.xprt и запустите расчёт. Проект настроен на 60 с, RK4, постоянный шаг 0.001 с. Шаг записи 0.01 с; ожидается 6001 строка от 0 до 60 с. После завершения в журнале появляется сообщение о достижении конечного времени. Временной график показывает y(t) после W3.

Блок «В файл» использует относительный путь output\signals_model.txt. При новом запуске этот файл содержит результат нового прогона. Перенос проекта в другую папку с сохранением output фактически проверен.

Параметры: ступенька 0→1 при t=0; сумматор [1,−1]; ИЭ «Экстраполятор», период 0.01 с; W1 «Интегратор», k=10; W2 «Инерционное звено 1-го порядка», k=2, T=1; W3 «Инерционно-форсирующее звено», T1=5, T2=2. Начальные условия нулевые. Блок «В файл» записывает e, y, xp в указанном порядке после времени.
