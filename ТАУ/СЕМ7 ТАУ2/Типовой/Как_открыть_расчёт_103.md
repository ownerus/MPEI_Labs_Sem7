# Типовой расчёт ТАУ2, вариант 103

Для сдачи: Типовой_расчёт_ТАУ2_вар103_Грудинин.pdf (19 страниц).
Редактируемая версия находится в одноимённом DOCX. «Типовой для подготовки»

## SMath

Откройте SMath_вариант_103.sm в SMath Studio и дождитесь пересчёта.
Лист содержит исходные звенья, дискретную функцию, точную/приближённую АФЧХ,
три проверки предельного усиления, корни, переходы при номинальном и предельном
усилении и расчёт ошибки линейного входа. Формулы редактируемые.
На графиках АФЧХ используется разреженная сетка для быстрого показа;
плотная проверка 5000 частот выполняется Python-файлом.

Контроль: Kпр≈52.120439; номинальное K=10; εст=0; εкин=0.05.
При предельном усилении колебательная составляющая не затухает.

## SimInTech

- SimInTech_модель_вариант_103.xprt — ступенька, K=10.
- SimInTech_предельное_усиление/Модель_вариант_103.xprt — ступенька, K=Kпр.
- SimInTech_линейный_вход/Модель_вариант_103.xprt — x(t)=t, K=10.

Каждая модель рассчитана до 60 с методом RK4 с шагом 0.0001 с
и сохраняет данные через 0.01 с.
Для повторения проверенного запуска открывайте проекты по одному в новом
экземпляре SimInTech: выходной файл создаётся в папке output рядом с проектом.
Переносите модель вместе с её папкой output. Порядок столбцов номинального
файла: t,e,y,xp; новых файлов: t,e,y,xp,x.
Файл output/signals_model.txt при новом запуске обновляется.
Сумматоры имеют веса [1,−1], сетка отключена.

## Проверка Python

Зависимости: numpy, scipy, sympy. На этом компьютере готовый интерпретатор:
C:\Users\grudi\MPEI\AI_agents\ТАУ2_Codex\Типовой_103\python-env\Scripts\python.exe

```powershell
python .\Расчёт_вариант_103.py
python .\Расчёт_вариант_103.py --regime nominal --simintech-output .\output\signals_model.txt
python .\Расчёт_вариант_103.py --regime critical --simintech-output .\SimInTech_предельное_усиление\output\signals_model.txt
python .\Расчёт_вариант_103.py --regime ramp --simintech-output .\SimInTech_линейный_вход\output\signals_model.txt
```

Параметр --export-dir указывает папку для выгрузки расчётных CSV/JSON.
Для показа преподавателю возьмите SMath-файл, все три проекта SimInTech
вместе с папками output и отчёт.
