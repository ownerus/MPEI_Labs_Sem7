# БАЗОВЫЕ МАТРИЦЫ И ЗНАНИЯ ПО ДИСЦИПЛИНАМ

### 1. МСУ (Моделирование систем управления)
- Объект: электрическая часть турбогенератора энергоблока ТЭС СГ2-500-4У2 (12-й порядок).
- Вектор состояния $x = (x_1 \dots x_{12})^T$:
  * $x_1, x_2, x_3$ — потокосцепления статора и ротора по оси $d$;
  * $x_4, x_5$ (или $y_1, y_2$) — потокосцепления статора и ротора по оси $q$;
  * $x_6, x_7, x_8$ (или $z_1, z_2, z_3$) — перемещение клапана, скорость и ускорение сервомотора;
  * $x_9, x_{10}, x_{11}$ (или $u_1, u_2, u_3$) — координаты регулятора (давление, расход, датчик мощности);
  * $x_{12}$ (или $s$) — скольжение ротора.
- Проверка сингулярной возмущенности:
  $$\frac{|\text{Re}(\lambda_{1,2})|}{|\text{Re}(\lambda_3)|} \ge 10 \implies \text{понижение порядка на 2 (с 12-го до 10-го)}.$$

### 2. УБС (Управление большими системами)
- Поуровневый структурный анализ ориентированных графов:
  * Порядковая функция $N_0 \dots N_m$: вершины $N_0$ имеют полустепень захода $d^-(a_j) = 0$;
  * Итерационный выбор $N_k$;
  * Защита от контуров (если $N_k = \varnothing$ при непустом остатке — граф циклический);
  * Топологическая перенумерация $\to$ верхнетреугольная матрица ($i \ge j \implies a_{ij} = 0$).
- Уравнение Беллмана (кратчайший путь в DAG):
  $$F(a_j) = \min_{a_i \in G^{-1}(a_j)} [F(a_i) + q(a_i, a_j)], \quad F(a_{\text{start}}) = 0$$
- Сохранение всех равноценных путей через список предшественников `parents`.

### 3. ННТвЗУ (Нейро-нечеткие технологии в задачах управления)
- Искусственные нейронные сети:
  * Формальный нейрон: $s = \mathbf{w}^T \mathbf{x} + w_0$, $y = f(s)$.
  * Производная логистического сигмоида: $f'(s) = \alpha y (1 - y)$.
  * Дельта-правило: $\Delta w_{ij} = \eta \cdot \delta_j \cdot x_i$, где $\delta_j = (y^*_j - y_j) f'(s_j)$.
  * Архитектуры: многослойный персептрон (MLP), радиально-базисные сети (RBF).
  * Тестирование: Confusion Matrix (матрица ошибок), Precision, Recall, Accuracy, процент распознавания $\ge 90\%$.
- Нечеткая логика и ГА:
  * Нечеткий вывод Мамдани (min-max композиция, центроидная дефаззификация) и Сугено (линейные синглтоны).
  * Генетические алгоритмы: кодирование хромосом, турнирная/рулеточная селекция, двухточечный кроссовер, мутация.

### 4. ТАУ-2 (Теория автоматического управления, часть 2)
- Анализ нелинейных систем:
  * Метод гармонического баланса: $W(j\omega) = -\frac{1}{W_{нл}(A)}$. Пересечение годографа Найквиста с $-1/W_{нл}(A)$ определяет параметры предельного цикла (автоколебаний).
  * Метод фазовой плоскости: особые точки (узел, фокус, седло, центр), предельные циклы.
- Дискретные системы управления:
  * Дискретные передаточные функции выводить в обозначениях и по таблицам из соответствующих лекций и практикума. Не смешивать переменные преобразования и не подменять вывод готовой формулой из другой схемы дискретизации; явно учитывать структуру импульсной системы и принятый способ фиксации сигнала.
  * Синтез цифровых регуляторов (квазинепрерывный метод и метод прямого синтеза).
- Пространство состояний:
  * Модальное управление (формула Аккермана), интеграл качества Ляпунова, наблюдатели состояния.
